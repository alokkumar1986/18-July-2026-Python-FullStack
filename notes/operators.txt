range() : It is function which takes 3 params

range(s,s,s)  : last and second last are optional

range(5)  : 0...4

range(1,5) : 1...4

range(1,5,2) : 1, 3

range() basically creates sequence of number. It is mostly used in for loop.

for I in range(101):
   print(I)

#write a program to print the numbers divisible by 2 between 1 and 100.

for item in range(1, 100):
    if item%2==0:
      print(item, end=" ")

Operators :

Basically these are the symbol given between two operand and it perform an operation and gives the result

There are following operators

1) Arithmetic
2) Comparison
3) Logical
4) Assignment 
5) Identity 
6) Membership 
7) Bitwise 
8) Special 


Arithmetic: +, -, *, /, //, **

+ : Addition : 5 + 3 = 8
- : Subtraction : 5 -3 = 2
* : Multiplication : 5 * 3 = 15
/ : Division : 5 / 3 = 1.666666 (The output is always in decimal)
// : Floor division : 5 // 3 = 1 (The output is always in whole number)
** : Exponent : 5 ** 3 = 125
% : Modulus  : 5 % 3 = 2

Comparison : These operators compare two operand and gives output True/False

== : equal to
> : greater than
< : smaller than
>= : greater than equal to
<= : smaller than equal to
!= : not equal to


Logical : and , or, not

a = 5
b = 3

print(a and b) # a is True , b
              # a is False, a


print(a or b) # a is True , a
              # a is False, b

print(not a) # False

Every number is always True, except 0, None, [], (), {}, ''

Identity : is , is not

a = 5
b = 5.0

print(a==b) #True
print(a is b) #False

print(a is not b) #True

Note : is operator checks both value and type.

Membership : in, not in (It checks whether a value is present in a sequence)

5 in range(5) # False
5 not in range(5) # True
5 in range(0,6) #True

'a' in 'aptech' #True
5 in [1, 2, 3, 4, 5]  #true
5 in (1, 2, 3, 4) #False

Bitwise Operator:

&  : bitwise and
|  : bitwise or
^  : bitwise xor
~  : bitwise NOT
>> : bitwise rightshift
<< : bitwise leftshift


a = 5 #convert it to bin
b = 3 #convert it to bin
print(a & b) #apply logical and  


a = 5  #convert it to bin 101
b = 3  #convert it to bin 011
print(a | b) # apply logical or 111 = 7

a = 5 #convert it to bin 101
b = 3 #convert it to bin 011
print(a ^ b)  #when only one is 1 between two operands, return 1 (0,1 / 1,0) 
              # in other cases return 0 (1,1/0,0)

a = 5  
print(~a)  # add 1 to the operand and change the sign.


a = 5  #convert it to bin 101
b = 3  # 
print(a<<b) # then left shift the digits by number of 2nd operand

a = 5
b = 3
print(a >> b)
