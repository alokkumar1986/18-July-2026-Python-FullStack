dictionary :
#===================

Dictionary (dict) is a collection datatype where items are stored in key, value pair.

syntax :

d = {
      'name': "Ardhendu",
      'age' : 38,
      'gender' : 'Male'     
    }

How to construct a dict :

1)student = {
      'name': "Ardhendu",
      'age' : 38,
      'gender' : 'Male'     
    }

2) student = dict(name='Ardhendu', age= 38, gender='Male')

3) student = dict([('name', 'Ardhendu'), ('age', 38), ('gender','Male')])


key :  number, string
value : number, string, list, tuple, set,  dict


example : 

1) course = { 0: 'MySql', 1: 'Python', 2: 'Power BI'}
   course = { 'course1' : 'MySQL', 'course2' : 'Python', 'course3': 'Power BI'}

2) pythonclass = {
   'course' : ['Basic', 'Numpy', 'Pandas', 'Matplotlib', 'Sci-kit', 'Django'],
   'Fee' : (10000, 15000)
}


How to access the values :

1)
course = { 0: 'MySql', 1: 'Python', 2: 'Power BI'}
