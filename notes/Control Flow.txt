Control Flow :

In python the control flow of the execution python program is from top to bottom as it is interpreted. 

But there are few statements which can make flow of execution to jump from one place to other.

There are following statements.

1) Conditional Statement
2) Iterative Statement
3) Transfer Statement

Conditional Statement :

1) if 

syntax :

if condition: 
  statement1
statement2

Here if the condition is true, then statement1 and finaly statement2 will be executed

if the condition is false , then only statement2 will be executed.

similarly,

1)
if condition: 
   statement1
   statement2
   statement3
statement4

when condition is true, all the statements will execute
when condition is false, only statement4 will execute

example :

#write a program to check the number is palindrome

num = input('Enter a number : ')
if num[:] == num[::-1]:
   print('Palindrome')


2) if else

syntax :

if condition:
  statement1
else:
  statement2

when condition is true, statement1 will execute else statement2 will execute

#write a program to check the number is palindrome

num = input('Enter a number : ')
if num[:] == num[::-1]:
   print('Palindrome')
else:
   print('Not palindrome')


2) if elif else

syntax : 

if condition1:
  statement1
elif condition2:
   statement2
else:
   statement3

here when condition1 is true, the only statement1 will execute
     when condition2 is false, then it will check condition2, if condition2 is true, then only statement2 will execute
     when condition1 and condition2 both are false, then only state
